## 我在解决什么问题

AI 应用（客服、内容、教育、编程助手等）跑久了会碰到四件事：

1. **上下文越来越贵**：历史越堆越长，单次请求成本与延迟跟着涨；
2. **压缩后信息丢失**：摘要/截断之后 Agent 忘了前面说过的**关键事实与约束**，出错还难查；
3. **记忆越用越乱**：该记的没记、不该记的记了，错了说不清依据；
4. **评测没口径**：改动前后到底变好还是变坏，说不清。

我做的是把「上下文压缩」与「记忆」当作可验收的工程对象：**关键信息保留率可量化校验；换会话/换模型行为可对比；每条记忆可追溯依据**。
